## One Sharing Rule for Google Drive Images

When Om uses Google Drive images in the dashboard, set each file to **Anyone with the link → Viewer**. Paste the normal Drive file link in the editor; the app converts it to a direct image-render URL automatically. A file that is not publicly viewable will not render for readers.
