# Open-Source Interaction References for Theorem of Kemet

This is a **research shortlist**, not a set of features to install wholesale. Every adoption should remain deliberate, preserve the Field Notes of the Necropolis visual language, and be tested against keyboard, touch, and reduced-motion needs.

| Repository | License checked | Best future use in Theorem of Kemet | Recommendation |
|---|---|---|---|
| [Nodlik/react-pageflip](https://github.com/Nodlik/react-pageflip) | MIT | A genuinely draggable long-form book once Om has multi-page visual essays. | **Consider later.** The current Field Folio uses a lighter original turn that better suits three short comparative records. |
| [Nodlik/StPageFlip](https://github.com/Nodlik/StPageFlip) | MIT | The underlying HTML/canvas page-turn engine for a future full-screen “facsimile room.” | **Consider later.** Use only when the interaction meaningfully improves reading; do not replace accessible article navigation. |
| [AdamRisberg/react-image-magnifiers](https://github.com/AdamRisberg/react-image-magnifiers) | MIT | High-resolution artifact, inscription, map, and papyrus inspection with touch support. | **Useful next upgrade.** Prefer it when Om starts filing images where detail is evidence, rather than decoration. |
| [xyflow/xyflow](https://github.com/xyflow/xyflow) / React Flow | MIT | An interactive **evidence relationship board** connecting a claim, artifact, source, counterargument, and related case. | **Strong candidate.** Make it a reader-facing optional investigation map, not a default replacement for normal article copy. |
| [clauderic/dnd-kit](https://github.com/clauderic/dnd-kit) | MIT | Future expansion of Om’s existing visual relic workshop or a source-card ordering desk. | **Useful only if the workshop grows.** The present workshop already has keyboard/touch fallback, so migration is not urgent. |
| [TanStack/virtual](https://github.com/TanStack/virtual) | MIT | Faster browsing when the journal grows into a large archive of records, letters, and sources. | **Reserve for scale.** Add when the archive is large enough that normal pagination or scrolling feels slow. |
| [vasturiano/react-force-graph](https://github.com/vasturiano/react-force-graph) | MIT | A more exploratory “constellation of cases” where readers pan through conceptual links. | **Optional / advanced.** It is visually powerful but can obscure scholarship if not given careful labels, filters, and a non-graph fallback. |

## Recommended Sequence

The best next visual capability is **evidence-image magnification** on actual high-resolution artifact or document images. After Om has more related cases and sources, build a small **React Flow evidence board** for one flagship investigation. Hold full drag-page libraries and force-directed graphs until the archive has enough real material to make them useful.

> **Reuse rule:** a library’s permissive license allows incorporation under its terms, but never justifies copying its demo artwork, branding, or distinctive visual composition. Theorem of Kemet should keep its own original Egyptian field-notes art direction.
