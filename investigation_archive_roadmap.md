# Theorem of Kemet — Investigation Archive Rollout

## Priority 1: Case Files and Evidence Board — Completed

The first release establishes the journal’s governing format: each published case carries a number, status, first-recorded date, location, editorial evidence guide, claim, documented record, counterargument, anomaly, theory, Om’s take, source trail, and curated related cases. This is the right foundation because every later room needs a reliable case record to point to.

## Priority 2: Timeline Rail

Build this next after Om has added a meaningful group of dated case records. The prerequisite is a structured `timelineDate` on at least ten published cases, with dates described as exact, approximate, BCE/CE, or modern reporting dates. The first version can be a data-driven horizontal rail with a case card at each event; it should not invent chronology where sources are uncertain.

## Priority 3: World Map

Build the map after Om has added real coordinates or defensible named locations for approximately fifteen records. Each pin should show the case status, its location note, and a link to the case file. The map must distinguish a site linked to a historical source from a location that belongs only to a modern allegation.

## Priority 4: Symbol Library

Build this once Om can supply at least twelve source-backed symbol records. Each symbol needs an image, origin or earliest known context, historical use, modern interpretation, conspiracy association if applicable, and cited source links. The experience should be a searchable object index, not a gallery of unexplained claims.

## Priority 5: Document Vault

Build when Om has public, shareable scans or PDFs with clear source rights and metadata. Each document needs title, date, creator/issuing body, source URL, document type, optional highlighted passage, and Om’s annotation. The first version should prioritize readable image/PDF viewing and citation over complex annotation tools.

## Priority 6: Specimen Viewer

Build last, after Om has properly licensed object photography or his own images. Each specimen requires a clear image set and factual metadata for material, period, location, context, symbol, and the question that makes it relevant. Rotation and zoom should come only after image rights and source facts are in place.

> The rule across every module is simple: **add an interface only when Om has real material ready to occupy it.** The current index cards reserve the visual homes without creating invented evidence.
